# LP1

Repositório de exercícios da disciplina de Linguagem de Programação I (LP1), com scripts em Python cobrindo os fundamentos da linguagem: entrada e saída de dados, variáveis, tipagem, operadores aritméticos, estruturas condicionais e laços de repetição.

## Conteúdo

| Arquivo | Descrição |
|---|---|
| [hello world.py](hello%20world.py) | Programa clássico "Hello, World!" |
| [bem vindo.py](bem%20vindo.py) | Saudação personalizada com condicionais (`if`/`else`) |
| [idadefutura.py](idadefutura.py) | Cálculo de idade futura a partir da idade atual |
| [iteracao.py](iteracao.py) | Contagem regressiva usando laço `while` |
| [senha.py](senha.py) | Validação de senha em loop até acerto |
| [exercicio01.py](exercicio01.py) a [exercicio20.py](exercicio20.py) | Lista de exercícios progressivos: apresentação pessoal, desenho em ASCII, tabuada, saudações, questionários, cálculo de idade, conversões de unidade, operações aritméticas básicas, médias, área e perímetro de figuras geométricas, cálculo de aumento salarial, conversão de moeda e cálculo de salário por hora |

## Requisitos

- [Python 3](https://www.python.org/downloads/)

## Como executar

Cada arquivo é independente e pode ser executado diretamente com o Python:

```bash
python exercicio01.py
```

Alguns scripts pedem dados via terminal (`input`), então acompanhe as instruções exibidas no console.
